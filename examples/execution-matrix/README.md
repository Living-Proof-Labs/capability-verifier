# Execution matrix interoperability sample

Generated by the unreleased adapter from released, commit-verified executors and
catalogs. `producer.commit` identifies the base checkout during development, not
a release of this adapter. This checked-in sample is for interoperability only;
`task matrix` regenerates fresh run identifiers and producer commit evidence.
Copy this entire directory. `manifest.json` has four coordinates; `controls.json`
is a separate bundle. The observations are unchanged Apache-2.0 verifier fixtures.
